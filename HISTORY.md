# Project history / История проекта

Automesh was developed privately before this public source repository opened.
The earliest surviving development commit is dated **30 April 2026**
(identity, seed, QR, storage and import). A deterministic P-256 identity
milestone was recorded on 13 May 2026. The node project was extracted from
the messenger in October 2026. LoRa USB/Bluetooth arrived in app 0.5.0.

This clean public history starts in November 2026. The older Git repositories,
operational records and deployment access remain private. The dates below were
transcribed from the archived Git tags; those historical tags, old binaries and
old CI logs have **not** been recreated in this repository. Version numbers
identify historical milestones, not downloads currently published here.

Проект разрабатывается с 30 апреля 2026 года — более полугода до открытия
исходников. Публичная история начинается с чистого снимка. Старые коммиты
не перенесены и не датированы задним числом; даты и версии этапов сохранены ниже.
