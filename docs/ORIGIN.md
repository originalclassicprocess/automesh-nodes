# Source origin

Automesh Nodes was extracted from the Automesh messenger in October 2026.
The original components were server/node, signaling/limits, the message wire
contract, account addressing, registration proofs and Windows packaging.
Both projects are MIT-licensed; original license/attribution files are retained.

Canonical public node source: https://github.com/originalclassicprocess/automesh-nodes
Public messenger source: https://github.com/originalclassicprocess/Automesh

This is a clean public snapshot, not the complete private Git history.
See [project history](../HISTORY.md) for dated development milestones.
Source manifests describe a compatibility snapshot, not a cryptographic audit.
