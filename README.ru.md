# Automesh Nodes

[English](README.md) · [История проекта](HISTORY.md)

Необязательная инфраструктура [Automesh](https://github.com/originalclassicprocess/Automesh):
общий протокол/ядро, зашифрованные очереди и отдельные адаптеры платформ.
Предварительный выпуск исходников; независимого аудита защиты ещё нет.

| Платформа | Состояние |
| --- | --- |
| Windows x64 | Исходники 0.4.16, новый мастер ПК / ПК + телефон |
| Linux Personal | Общее ядро 0.4.16, прежний мастер HTTPS в терминале; Windows-мастер не перенесён |
| Server / cPanel | Отдельные адаптеры сервера/Passenger, настройка оператором |
| macOS | Проверки общего ядра; установщика и мастера нет |

Эта чистая копия не переносит старые приватные сборки и журналы GitHub.
Ранее распространялись Windows 0.4.16 и Linux/server 0.4.12. Новые сборки
Actions — кандидаты; установка Linux в чистой виртуальной машине ещё нужна.

Цели: децентрализация, хранение на своих устройствах, шифрование личного
общения по умолчанию и понятная настройка. Уже есть авторизованные очереди
текста/файлов, подтверждения, сроки, отмена отправителем, квоты, отдельные
текстовые ящики устройств, сигналинг и восстановление состояния после рестарта.
Сид остаётся у клиента. Нода видит метаданные; приём нодой не равен прочтению.

Для разработки нужен Node.js 24 (минимум 22.12):

```sh
npm ci --ignore-scripts
npm test
```

Сборка на соответствующей ОС: `npm run build:windows` / `npm run build:linux`.
На Linux также `node scripts/check-server-unit.mjs`. Сборка не устанавливает
службу, не запускает ноду, не добавляет сертификаты и не меняет firewall.
Не используйте настоящие ключи, очереди и бэкапы в тестах.

переведён. Нет гарантий доставки, анонимности или готовой глобальной сети.
